┌───────────────────────────────────────────────────────────────────────────┐
│  📝 FLUJO DE UNA PETICIÓN                                                 │
└───────────────────────────────────────────────────────────────────────────┘

    1. Cliente hace petición: GET http://localhost:3000/products
       └─> Header: Authorization: Bearer <token>

    2. Gateway recibe la petición
       └─> JwtAuthGuard valida el token
           └─> Si válido: continúa
           └─> Si inválido: retorna 401

    3. ProxyController reenvía al monolito
       └─> GET http://legacy-monolith:3001/products
       └─> Con todos los headers originales

    4. Monolito procesa y responde
       └─> JSON con lista de productos

    5. Gateway reenvía la respuesta al cliente
       └─> Con el mismo status code y headers
