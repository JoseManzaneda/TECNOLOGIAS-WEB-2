# Catalog Service

Este directorio está reservado para el microservicio de catálogo de productos.

## Propósito

El Catalog Service será responsable de:

- Gestión de productos
- Gestión de categorías
- Gestión de ingredientes
- Relaciones entre productos e ingredientes
- Búsqueda y filtrado de productos
