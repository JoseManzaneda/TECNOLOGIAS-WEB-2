# User Service

Este directorio está reservado para el microservicio de gestión de usuarios.

## Propósito

El User Service será responsable de:

- Gestión de usuarios (CRUD)
- Autenticación y autorización
- Gestión de perfiles
- Gestión de direcciones de usuarios
- Sistema de puntos y recompensas
