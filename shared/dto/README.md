# Shared DTOs

Este directorio contendrá los Data Transfer Objects (DTOs) compartidos entre los diferentes microservicios.

## Propósito

Los DTOs compartidos permiten:

- Mantener contratos consistentes entre servicios
- Reutilizar validaciones comunes
- Facilitar la comunicación entre microservicios
- Reducir duplicación de código

## Ejemplos de DTOs a compartir

- DTOs de paginación
- DTOs de respuesta estándar
- DTOs de filtros comunes
- DTOs de eventos entre servicios
