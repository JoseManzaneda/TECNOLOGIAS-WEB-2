# Shared Interfaces

Este directorio contendrá las interfaces TypeScript compartidas entre los diferentes microservicios.

## Propósito

Las interfaces compartidas permiten:

- Definir contratos de tipos comunes
- Mantener consistencia de tipos entre servicios
- Facilitar la integración entre microservicios
- Mejorar la documentación del código

## Ejemplos de interfaces a compartir

- Interfaces de entidades base
- Interfaces de respuestas HTTP
- Interfaces de configuración
- Interfaces de eventos del sistema
